# Ω Sustainability Layer v1

This layer preserves continuity without changing the frozen Core Genome, Main Signed Head, Host Assurance Head, Autorecover v4.3, or bounded Production Head v1.0.0.

The fail-closed CI must verify exact mirrored v4.3 and v4.2 recovery bytes, current/fallback pointers, bounded production identity, monotonic operational evidence, required critical files, and a disaster-recovery drill on every push/PR/daily run.

No private signing key is stored here. If secure signing continuity is unavailable, promotion of a new Main Signed Head is blocked; the existing signed v0.8 head remains unchanged.
